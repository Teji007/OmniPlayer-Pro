# Third-Party Licenses

This directory contains third-party license and attribution information for components used by OmniPlayer Pro.

The exact license obligations depend on the versions and binaries included in a particular release.

Before redistributing a release, verify:

1. The exact dependency versions.
2. The exact Qt binaries.
3. The exact FFmpeg binaries and configuration.
4. Any optional AI/runtime components.
5. All applicable copyright notices.
6. All applicable source-code or offer-for-source obligations.
7. Commercial licensing requirements.

See `THIRD_PARTY_NOTICES.txt` and the release SBOM in the repository root.
