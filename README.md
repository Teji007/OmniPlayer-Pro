# OmniPlayer Pro

**Advanced Windows Media Player**

Developed by **Tejinder Pal Singh**

OmniPlayer Pro is an advanced Windows media player built with Python, PyQt6, Qt 6 and FFmpeg. It combines modern playback features with media processing, AI-powered subtitles, media inspection, playlist management and smart-media tools.

## Features

* Video and audio playback
* AI subtitle generation
* AI transcription
* AI chapter generation
* Subtitle timing repair
* Subtitle editing
* Multiple subtitle export formats
* Playlist management
* Media library
* Resume playback
* Bookmarks and A/B looping
* Frame stepping
* Screenshot capture
* Contact sheet generation
* Scene detection
* Keyframe extraction
* Video processing
* Audio DSP
* Audio normalization
* Loudness analysis
* FFmpeg media conversion
* Chromecast support
* DLNA/HTTP media serving
* Media metadata lookup
* Hardware telemetry
* Media stream inspection
* Secure media features
* Voice control
